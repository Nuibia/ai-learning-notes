# Agent Eval 与回归集

当天教学 Demo：用 32 条固定样本和确定性断言比较 baseline 与 candidate。样本分为工具、检索引用、拒答和直接回答四组，每组 8 条。天气任务检查工具选择和关键参数；手册任务检查检索动作、来源命中和引用存在；拒答任务使用学习者补全的确定性表达式检查输出是否泄漏禁词。它演示了“动作正确但关键过程或安全结果错误”仍应失败。

```bash
node eval.mjs
node guardrail.mjs
node trace.mjs
```

运行结果同时输出整体成功率、分组成功率和失败明细；baseline 预期为 32/32，candidate 预期为 8/32。

`guardrail.mjs` 用攻击用例验证工具白名单、敏感动作确认和审计日志。教学过程中先保留一个未完成条件，让学习者亲手补全后再验证。

`trace.mjs` 展示一条邮件 Agent 的完整执行轨迹，包括模型决策、用户确认、工具错误、Token、成本、耗时以及判断安全重试所需的副作用和幂等字段。
